# План лендинга «Клуб 150» (утверждён к работе, ждёт команды «делай»)

Сохранено 2026-11-03. Делать по скиллам `website-design:landing-page` + VectorLab UX, стиль из `DESIGN.md`.

## Где
Отдельная страница (например `about.html`), само приложение `index.html` не трогать.
Добавить её в `sw.js`, если нужна офлайн, и поднять `VERSION`.

## Секции
1. **Первый экран:** «Жим 150 кг за 13 недель: программа в телефоне». Кнопка «Открыть программу». Визуал: скриншот главного экрана (`docs/screenshot.jpg`).
2. **Что внутри:** 3 тренировки в неделю в любые дни; раскладка блинов на штанге; таймер отдыха; калькулятор 1ПМ и график роста.
3. **Как устроены 13 недель:** лёгкие, тяжёлые и облегчённые недели (4-я и 8-я облегчённые), прогрессия веса.
4. **Работает без интернета:** установка на рабочий стол (Android сразу, iPhone через «Поделиться → На экран Домой»).
5. **Вторая программа «Сила и рельеф»:** 12 недель, 5/3/1 Вендлера + 5×5, калькулятор питания на сушку.
6. **Вопросы** («подойдёт ли новичку», «нужен ли зал/какой инвентарь», «где хранятся отметки») и повтор кнопки.

## Правила
- Не выдумывать отзывы, результаты учеников, число пользователей.
- Фото только из `img/` с указанием авторов.
- Проверить: 375 / 768 / 1440 px, только клавиатура, контраст, title/description/og:image.
