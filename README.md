# Клуб 150 — программа жима лёжа на 13 недель

Мобильное веб-приложение по гайду «Твоя программа тренировок». Открывается по ссылке https://glanass1204-web.github.io/club-150/ или одним файлом `index.html` в любом браузере.

- **Максимумы.** Вводишь 1ПМ в жиме, приседе и становой — каждый процент программы сразу показан в килограммах на штанге (гриф 20 кг, шаг 5 кг) и какие блины вешать на каждую сторону: 25, 20, 15, 10, 5, 2,5 кг.
- **Калькулятор 1ПМ.** Вес × повторения в отказ (до 12) → рекордный вес и таблица 95–50 %. Формула — среднее Эпли, Бжицки и О’Коннора; результат в целых килограммах (90 кг × 8 → 111 кг).
- **Инвентарь:** штанга, EZ-гриф, гантели, скамья для жима, наклонная скамья. Блоки, тренажёры, турник и гиперэкстензия заменены на свободный вес.
- **13 недель × 3 дня** (Пн/Ср/Пт), базовые упражнения отмечены, суперсеты сгруппированы, альтернативы «или» сохранены.
- **Отметки «сделано»** и выбранная неделя хранятся в браузере. Ссылка `#w5` открывает сразу 5-ю неделю.
- **Цитата недели** и блок «Опыт великих»: Хейни, Коулман, Шварценеггер, Вендлер, Роллинз, Риппето, Дэн Джон, Сенека.
